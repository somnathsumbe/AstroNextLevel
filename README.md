# Astro Market Analysis — Basic Next.js Repository

## Stack
- Next.js
- React / HTML5 semantic markup
- Bootstrap 5
- JavaScript
- Local JSON data

## Included now
- Login page
- Register page
- Header
- Footer
- Sidebar navigation
- Dashboard
- 14 blank module pages
- JSON data placeholders

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000
